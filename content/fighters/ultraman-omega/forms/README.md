## 切换提案的边界

以能量满3格、体力不高于一半、每局一次为共同条件，演出全程无敌、计时暂停，完成后持续到局末。建议第一次22结束时按相对前/中立/后/上加P选定一套；本局不能再换装或回本体。理由是输入能覆盖四套且沿用现有解析语义，禁止利用来回切换获得多次无敌；多个装甲的打法差异交给赛前练习与下一局选择。上方向分流需要未来机制会话处理跳跃优先级，本轮没有实现。
若指挥认为上方向太难，备选为训练/选人流程中的“本局装甲偏好”设置，战斗中仍只输入22+P。此为机制提案，不能因此让四套装甲直接成为选人可用角色。
首次定稿只证明外形；本体第7阶段完成后，每套装甲另开完整矩阵、发射点、特效与声音专案。加美顿影视首次登场话数仍待核，不从“第16话讲加美顿数据”倒推首次登场。其电视作品是2026年《奥特曼 新世代之星》，不能填成欧米伽2025正篇的一话。
