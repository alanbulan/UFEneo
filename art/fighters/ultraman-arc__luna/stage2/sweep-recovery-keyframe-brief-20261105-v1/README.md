本张是参考2低位扫腿之后、参考3恢复低架之前的一张真实收腿中间相，不是再次出脚、跳跃、换脚攻击或站立。按画面可见的前后层腿辨认，不把屏幕左右误写成解剖左右：参考2画面左下的近层亮色承重腿继续承重，脚底稳定接地，膝盖深屈，骨盆维持低位；该腿不要突然越到画面右方，也不要抬成悬空后腿。参考2向画面右伸出的远层扫腿正在屈膝收回，右侧脚踝沿低位向身体靠近，离伸直接触位明显缩短，但尚未完全达到参考3的最终低架。保持这条腿从髋部到膝、胫、踝的连续关系和前后遮挡，不通过两腿交换身份实现回收。扫腿脚接近地面准备落位，不能再次向前绷直踢出，不能穿入支撑腿，也不能突然挪到身体另一侧。

上身随着收腿略回正，头面仍看向画面右；肩、胸、腰和髋自然协调，不用单独平移上半身。两臂由扫腿时的低位向护架收回，双拳保留，腕部蓝色圆甲属于原来的臂；没有手掌撑地，不增加撑地手，不借手支撑起跳。姿态明确处在“扫完正在收回”而不是蹲姿终点。保持统一像素边缘与有限色阶，不使用模糊、运动拖影、光效、速度线、地面、阴影底板、文字、参考拼贴或多个连续人物。输出单张完整人物RGBA PNG，透明背景，不能用棋盘格图案冒充透明。
