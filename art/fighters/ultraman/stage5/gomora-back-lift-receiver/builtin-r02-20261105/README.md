## 已知问题

三版可识别为初代，但C型脸部、共同体尺和完整前后相仍未验收。骨盆最低点与实际腹侧必须分开：将最低臀缘贴背可以避角，却不自动证明腹腰承重。第二版更值得继续审，其角色更接近抬胸卸重过渡；当前尚不能直接充当最低承重母相。

ROI是矩形诊断，不是人体精确分割。Alpha交叠不等于穿体，零交叠也不代表动作成立。不以层序遮挡掩盖问题，也不因轻微细差宣称角色身份错误。
