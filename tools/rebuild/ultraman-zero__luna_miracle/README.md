## 方向规格（写提示词前定死）

只按 `ref-03` 正面 + `ref-02` 右侧脸 + 已装 `assets/fighters/ultraman-zero__luna_miracle/catalogue/model-native.png` 侧视像素交叉核对：

- **双蓝冠鳍（头镖）**：左右对称，根部在额侧太阳穴上方、银色中央冠脊两侧；刃身先向上、再向后上方弯掠，尖端位于头顶后方、约与后脑上缘齐平。侧视近侧鳍遮远侧，只露一条更暗的远侧刃尖；外缘有一处轻微转折/凹口，内缘贴头壳。不得画成向前弯、第三根独角或平直长直角。
- **银色中央冠脊**：从绿色额灯上方起，沿头顶中线向后，止于冠顶小尖；侧面看是眉上方的银色脊线。后脑下缘有一小片向后的银色壳体，是头盔后缘，不是第三根冠。
- **额灯**：青绿色小圆灯，位于双眼上方正中、银色眉板内。
- **眼与面罩**：黄色杏仁眼，向太阳穴上挑；银色面罩与下颌板，深蓝颈部。
- **胸肩甲**：银色层叠板覆盖双肩顶、上胸并延伸到肩胛；层叠边朝后下方分级。银色胸板呈 V/Y 收向胸骨中央的蓝色椭圆胸计时器（银边）；其下银色/白色 X 与 V 纹横过腹部和髋部。
- **蓝色四肢**：深蓝臂腿，蓝拳套与蓝靴；左腕银蓝 Ultra Zero Eye。外侧大腿至小腿有白色/银色纵纹，躯干侧面有白线。四肢正常粗细，不增肌，不加厚装甲。
- **体量**：原生站高 188（冠顶→鞋底），头肩与本形态皮套一致；待机照按站高 1100 生成，落格按 188 同口径核。
