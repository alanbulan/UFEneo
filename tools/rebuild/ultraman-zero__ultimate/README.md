### 朝向规格（写提示词前已定死）

以下坐标取自 `side-right-90-figuarts-review.jpg` 原图（角色朝右）。眼列 x≈565–600、y≈285–320；头顶最高 y≈175；鞋底 y≈1535，身高中段约 1360 px。

- 头冠：额前小尖角在眼列之前（右），指向前上；头顶后缘的冠形向后方收，不向前伸出。
- 双头镖：贴头壳，宽基座在耳上/太阳穴，刃缘有凹口，镖尖向后（左）上方掠起；镖尖 x 小于眼列 x，位于头后，不伸到面前。近侧镖遮远侧镖。
- 肩后薄刃（两枚，左右各一）：位于头部之后（x≈290–380，全在眼列左侧），近乎竖直，刃尖 y≈45，高于头顶约 130 px（约身高的 9.6%）；刃根在肩胛上方 y≈450。不得画成胸前刃、向前伸的角或第三根头冠。
- 肩甲主翼：覆盖肩部，翼尖 x≈400–470、y≈205，位于眼列之后、头顶之下（略高于眼线）；前缘向右下斜到胸前 x≈650，后缘向后下收，最低尖角在肩胛后下方（x≈290、y≈650）。主翼参与人物侧轮廓，但不是披风，不垂到腰下。
- 胸甲：银色层叠胸板位于胸前（x≈620–700），比胸廓向前凸出；下端在胸骨/上腹处收成向下的尖角；中央蓝色宝石在正面与近侧 3/4 可见。胸甲后方经颈后环带连到背部，背中央有一条纵向银色脊片。
- 右前臂刃（究极赛罗之剑）：银色长刃沿右前臂外侧安装，刃尖越过拳头继续向前；星形护手在腕部，刃身有两枚蓝色宝石。手臂下垂时刃随前臂向下；抬拳护胸时刃必须朝前下方伸出，不得指回自己的头、眼或左拳。
- 识别色：银甲、红蓝银身体、黄色眼、绿色额灯、肩甲/背刃/前臂刃的蓝色宝石；红靴。不得用基础赛罗的无甲配色顶替。
- 侧视遮挡：近侧主翼与近侧背刃遮住部分远侧同名结构；头部与双手必须保持可辨，盾甲不得盖住眼睛或拳头。

- 待机照片：纯右侧视 90°、全身不裁切、无 FX/地面/文字/边框；脚外缘间距 ÷ 站高 0.65–0.80；前后脚屈膝下沉；双拳胸前护架；对照本规格核头冠、头镖、背刃、主翼、胸甲、前臂刃的前后朝向与转折。
