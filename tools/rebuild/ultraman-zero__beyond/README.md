  **刃尖向后上方折起**；近侧头镖遮住远侧；侧视只见贴头壳的弯刃，不是向前伸的长直角、羽片或第三根头冠。
  后视可见四枚刃尖向后外展开。

  背面：肩胛与背阔有紫色火焰纹，腰背有紫色 V；背中央一条银色脊柱脊从颈后到尾骨。
