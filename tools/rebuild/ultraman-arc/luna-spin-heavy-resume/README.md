# 月亮回旋十槽主游戏RAM候选

本轮只用已保存的完整本人源，不调用用户Codex、不生图、不收费、不安装到assets或开放装甲。候选在主游戏main的训练入口以临时定义和贴图覆盖验证，不建立研究场景。

## 尺度与足路

顺序为实际idle00、卸重、蓄势03、跨身中相、展开、接触、初收、低收、左侧空中回摆02、实际idle00。排除旧landing、回摆01、backstep00，不为使用旧图引入脚路反向。

v10统一头代理尺出现蓄势变大/展开缩小，未直接拿去运行；v11每相使用同一规则sqrt(耳侧到下颌代理倍率×支撑膝踝倍率)，两尺同权重，仅完整整图等比缩放和前掌ROI锚定。它是保守试排折中，不是精确骨长或头身验收；遮挡和投影缩短仍有不确定。Forge RGB及Alpha128清理原源低透明噪点，原始字节不变。禁止局部缩放、切肢、旋转肢体或贴FX伪装动作。

实际idle只取phase00作首尾和静态对照，不能声称六相idle循环已通过。首尾与候选idle逐字节相同。完整原源大小各异，核各自等比采样误差<1%、整图无裁切，不再沿用升拳“所有源同方形大小”的断言。

## 时序和玩法

10槽ticks=[2,2,2,1,2,4,3,4,4,4]，沿原回旋9启动/4有效/15恢复，共28tick；没有延长招式填缺相。仅contact索引5使用脚背前缘真实Alpha框[64,80,20,16]，伤害100、体力30，其余规则沿用普通亚刻spin_heavy；候选禁用旧取消窗口，不加无敌或改变受方升空。后方向+HEAVY的真实InputFrame经正式解析器触发4K，不直接赋值move_id。命中与格挡初始距离110、落空260，双向验证。

## 执行与证据

register.py拒绝覆盖已登记目录；test_check.py独立核登记。main_bundle.py freeze封存依赖SHA，run通过tools/godot_lock.py串行执行主游戏原输入/独立回放。用隔离XDG，未触碰用户存档。图形核需要720/1080双向、冻结原生尺寸截图和安全区；技术通过不能签整招顺滑、听感或真人键盘。

重点观察入蓄抬臂/体量、蓄势到展开的缩身感、低收跨身到左回摆及落回idle鞋向与移重。未充分验收不安装。
