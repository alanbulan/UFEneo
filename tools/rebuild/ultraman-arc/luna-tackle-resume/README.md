# 月亮装甲S2突进撞击候选

本流程使用八张既有独立完整人物源，不生图、不收费、不开放未齐装甲。候选仅保存在art，通过正式main内存注入检查，不回写正式content/assets。

## 按序选择与实看

production-plan中heavy之后为launcher、spin_heavy、crush、tackle。前三者虽源齐，却分别只有平直伸拳、无背面回旋收势的侧踢、举顶后直接回架而无下砸接触，因此保留动作缺口，不靠击飞或破防数值伪造完成。tackle有迈步蹬地、前倾护面、整体前顶和落脚回架，可继续候选注册；实际接触是护面前臂/腕甲随躯干撞入，不声称裸肩先触。

## 整帧注册与判定

八张实际源均为1254×1254 RGBA，SHA逐项核既有来源；统一整张缩到159方，沿用已固定Forge模块、RGB32色色板与Alpha128。不采用旧诊断逐相面积缩放。每相整图仅平移到320方，x固定80，真实足底对齐280；不切肢、不旋转贴肢、不按面积逐相缩放。

第2/3/4相实际前臂腕甲的样本矩形分别为[134,53,144,69]、[139,46,149,62]、[133,56,143,72]，对应根点局部攻击框[54,77,10,16]、[59,90,10,16]、[53,77,10,16]，Alpha占比分别约95.6%、91.3%、88.8%。其他相无攻击框，不沿用本体45像素宽的空气框。

原规则4/9/13 tick、100伤害、30体力、0能量、推退8、逐tick突进总27、取消和反馈保持；不加无敌、不改变mid属性，不赋予击飞或倒地。八相时长为[2,2,3,3,3,3,4,6]。

## 工具和检查

- prepare.py：新目录建立共同尺度样本，拒绝覆盖。
- registration-review.json：记录实际目视签收，仅批准继续注册，不冒称用户亲审或最终美术通过。
- register.py：整图注册、本人Alpha受击框、atlas及候选move/clip，拒绝覆盖。
- test_check.py：来源、整图像素、Alpha/色板、时序、实际接触框、规则不变、输入与关闭标志。
- main_bundle.py：封存资源与代码SHA，输出至reports/luna-tackle-resume的新合同，不覆盖旧输出。

正式main入口tests/review/fighters/ultraman-arc/luna_tackle/main_entry.gd，传--contract和--out，可选--left、--kind=hit|block|whiff、--tape。真实输入仅tick20相对前+CRUSH（O），其余中立；对手格挡使用真实GUARD输入。无头不生成窗口截图；图形须传--window-size=1280x720或1920x1080，经窗口稳定门与逐相冻结截图门，保留HUD、隐藏候选训练说明板。

所有Godot运行经python tools/godot_lock.py串行，隔离用户数据。逻辑与回放通过不等于美术、本人声音、真人硬件或4.7通过；这不是完整S2，更不是完整装甲。无录屏。
