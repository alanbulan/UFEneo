# 武器覆盖与记录格式

范围是所有已装英雄、怪兽、宇宙人及其具体形态在原剧中使用过的武器。这里定义工作标准，不重复维护完成度；当前实际状态和接手顺序以HANDOFF和运行数据为准。

每条武器登记：本人/形态ID、规范名称与别名、作品/版本/集数/时间点、来源URL及文件SHA、完整轮廓与持手、召唤/握持/收纳、原剧攻击方式、本作输入/动作ID/费用/取消窗口、人物/脱手物/FX/声音、双向命中/防御/落空与原输入回放、剩余问题。

人物与手持武器一起生成完整像素帧。脱手物使用本人专属资源和实际判定；不贴通用武器、不换色充数，不以图鉴装备图或静止人物加FX冒充完成。原剧动作和本作连招编排须分开注明，不虚构官方招名。

已有原剧依据的武器招缺触发位置时，用户已允许替换凑数的指令/派生技；记录旧招到新招、输入、费用和判定变化，基础移动/常用拳脚保持。当前清理任务不执行这些替换，须等用户新的开发指令。

八套装甲分别核对本人武器与形态归属。赛文头镖、杰克手镯变形、亚刻之眼剑、布莱泽持剑、欧米伽头镖及装甲、提欧具体版本武器等均不能互借整帧。名称或集数未知时留待核，不把“尚未核实”写成“没有武器”。
