# 战斗形态

运行登记以content/catalogs/battle_forms.json及battle_form_rules为准；不得把静态图鉴或旧制作计划的状态当成正式变身可用状态。

- E是独立形态键，旧22+P入口仍可兼容，具体费用和可用条件读当前数据。
- 本体到EX采用完整definition切换，要求EX自己的招式、整帧、技能和声音；EX哥莫拉、EX雷德王也可从正式选人页直选。
- EX形态保持至KO和胜败结算，新局重新建立。表现慢放不得暗中恢复本体。
- 只有轮廓相同、纯配色变化才允许共用帧；新增装甲、武器、体型差异必须制作独立动作。
- 亚刻太阳/月亮/银河、布莱泽法德兰、欧米伽雷基尼斯/特莱加隆/瓦尔基涅斯/加美顿八套装甲，仍须各自完整S2–S7矩阵和正式变身闭环。
- 当前月亮装甲有有效在制移动、跳跃、轻击源，接受某动作不等于全套装甲开放；准确接续见HANDOFF。

不要重新运行已清理的旧安装器。扩展形态时使用通用路由和数据协议，不在模拟中按角色复制逻辑；验证费用、失败入口、旧输入、直选、KO、R再战和原InputFrame回放。
