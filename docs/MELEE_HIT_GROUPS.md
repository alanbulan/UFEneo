# 独立实体攻击段

只有实际有独立挥击动作和可见接触区的多段实体招式才声明本数据。它不生成动作，不赋予必杀差异豁免，也不让同一束重复扣血。未声明的旧招继续整招最多接触一次，战斗快照不增加字段。

招式 `kind` 为 `strike`，在招式根的 `hit_groups` 中定义各段覆盖值，并在相应生效帧设置正整数 `hit_group`：

```json
{
  "kind": "strike",
  "hit_groups": {
    "1": {"damage": 35, "knockdown": false},
    "2": {"damage": 45, "knockdown": false}
  }
}
```

第一段生效帧填 `"hit_group": 1`，第二段填 `2`。每段必须有实际 `hitboxes`，空框帧不得声明段。一次发动中，同一段只接触一次，包括防御、实体护屏和后续重复进入同段。前段落空或被无敌避过不会消耗后段。再次发动、被打断或自然收招都清除记录。

每段可覆盖 `damage`、`chip_damage`、`stun`、`hitstun`、`blockstun`、`pushback`、`knockdown`、`launch`、`bounce`、`unblockable`、`level`。未覆盖的值继承本招。整数不得填小数；伤害、削血、硬直、眩晕不得为负；击退允许有方向。`level` 使用 `mid`、`low` 或 `overhead`。段编号必须与定义一致，禁止缺失或未引用的段定义，也不能覆盖招式类型、资源、成本或脚本。

连段后接飞行物时，用现有帧级 `shots`。弹体继续使用自己的接触记录、判定和寿命，不消耗实体攻击段。招式根值供最后一击或弹体读取，不能把总伤害重复分给每一段。非终结段通常不击倒，并按实际相间距给受击硬直；这些数值仍须在实际对战中验证，不能凭动画有两刀就认为连段成立。

真实段接触保存在角色 `combat.hit_groups`，参与状态哈希和原输入回放。`combat.connected` 继续表示本次发动曾有接触，`confirmed` 仍只表示命中确认，保持取消与落空分支语义。实体护屏按本段的不可防御属性判断。

`tests/melee_hit_groups.gd` 默认输出到用户缓存，可重复运行；传 `--report-dir=res://reports/review/<日期>/<主题>/` 保存本次输入和结果。`--replay` 在独立进程读取相同目录的原输入。旧历史基线及报告已经清理，`--baseline` / `--check-legacy` 是历史制作接口，不属于当前验证入口，不应用它们重新建立旧规则基线。
